# dsh-settings-resize

[English](README.md) | 中文

dsh-settings-resize 是一个 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 插件，让设置对话框可以调整宽度和高度。拖动面板右侧或底部边缘即可改变尺寸，标题栏右上角的两个按钮可以还原默认尺寸或铺满 DSH 窗口，下次打开会沿用上次的尺寸。

DSH 的设置窗口是固定的 800 × 800 弹窗。在宽屏显示器上，它两侧会空出很大一片；窗口较矮时又可能超出屏幕；而且没有内置设置可以修改这两个方向。这个插件在面板右侧和底部各加了一个拖拽手柄，并在关闭按钮左侧加了还原与全屏两个图标按钮。面板保持居中，向两侧同时伸缩。

## 安装

1. 下载或克隆本仓库。
2. 在 DSH 中打开 **插件（Plugins）**，选择 **添加插件（Add plugin）**，选中本目录（包含 `package.json` 的那一层）。
3. 刷新页面并打开设置。面板右侧和底部会各有一条指示条，标出拖拽手柄的位置；关闭按钮左边会出现两个图标按钮。

插件以本地 bundle 的形式安装，直接跟随本目录中的文件。移除该 bundle 并刷新后，就会恢复默认的 800 × 800 对话框；不会修改 DSH 安装目录里的任何文件。

## 使用

| 操作 | 效果 |
| --- | --- |
| 把鼠标移到面板右侧或底部 | 指示条变亮，并弹出提示说明操作 |
| 拖动右侧手柄 | 在 560 px 到「视口宽度 − 48 px」之间调整宽度 |
| 拖动底部手柄 | 在 420 px 到「视口高度 − 48 px」之间调整高度 |
| 点击还原按钮 | 回到默认的 800 × 800，并清除已保存的尺寸 |
| 点击全屏按钮 | 铺满 DSH 窗口；再点一次恢复之前的尺寸 |
| 双击手柄，或聚焦后按 Home | 同时还原宽高，并清除已保存的尺寸 |
| 聚焦手柄，按方向键 | 每次调整该方向 16 px（按住 Shift 为 64 px） |

拖动或用键盘调整时，手柄上会显示当前尺寸，格式为「宽 × 高 px」。每个手柄都带有 `separator` 角色、可访问名称和实时的 `aria-valuenow`；两个按钮既有 `aria-label`，也有悬停提示，不用鼠标也能完成全部操作。

## 功能

- 拖动右侧边缘调整宽度、拖动底部边缘调整高度；面板始终居中，所以两侧对称伸缩。
- 标题栏的还原按钮一键回到 800 × 800，全屏按钮一键铺满 DSH 窗口。
- 选定的尺寸保存在 `localStorage`，关闭设置、刷新页面后仍然生效。
- 键盘调整：方向键微调，Shift 加速，Home 复位；所有控件都有提示文字。
- 调整时显示尺寸数值，标签支持中英文。
- 只在视口宽度不小于 768 px 时启用，也就是 DSH 使用居中桌面弹窗的布局；低于该断点时 DSH 的整屏布局不受影响。
- 手柄和按钮是挂在 `<body>` 上的独立元素，根据面板的包围盒定位，因此面板的内边距、滚动条和圆角都保持原样。
- 不修改 DSH 的任何文件：禁用插件后就是出厂设置窗口。

## 配置

没有设置页面，插件只读写两个值：

- 存储键：`dsh.settings-resize.width` 和 `dsh.settings-resize.height`
- 默认尺寸：800 × 800 px
- 最小尺寸：560 × 420 px
- 最大尺寸：视口尺寸每个方向减去 48 px

双击手柄、按 Home，或点击还原按钮，会删除已保存的值，回到 800 × 800。全屏状态不保存；关闭设置后会停留在最后一次拖出的尺寸。

## 兼容性

在 Windows 上的 DSH 0.2.2-rc.5 中开发和测试。包的 `engines.dsh` 声明为 `>=0.1.0-rc.8 <0.3.0-0`，与其他已发布的前端插件一致。

插件通过对话框的公开属性 `data-shortcut-modal="settings"` 定位面板。如果未来的 DSH 版本删除或改名这个属性，插件就找不到面板，保持静默，显示原本的设置窗口。

## 实现说明

- `index.js` —— bundle 的宿主端；运行时不注册任何东西。
- `client.js` —— 全部功能：注入一个 `<style>` 把两个 CSS 自定义属性写到面板上，把两个手柄和一组按钮挂到 `document.body`，根据面板的包围盒定位，并处理指针与键盘输入。
- `cordis.patch.yml` —— 添加插件行的 bundle patch。
- `locale/en.json`、`locale/zh.json` —— 插件标题、描述，以及手柄和按钮的文案。

尺寸以 `--dsh-settings-resize-width` 和 `--dsh-settings-resize-height` 写在 `<html>` 上，作用域为 768 px 及以上的视口。全屏状态是 `<html>` 上的一个独立属性。`document.body` 上的 `MutationObserver` 会在对话框打开时挂上控件，关闭时移除。

## 开发

没有构建步骤：包内是普通的 ES 模块。修改后运行 `node --check client.js`，再重新安装或刷新 bundle，打开设置查看效果。

仓库就是一个目录；`package.json` 的 `files` 列出了打包发布所需的全部文件。
