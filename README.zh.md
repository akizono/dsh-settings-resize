# dsh-settings-resize

[English](README.md) | 中文

dsh-settings-resize 是一个 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 插件，让设置对话框可以调整大小。拖动面板的任意一条边或任意一个角，就能同时改变宽度和高度；面板标题栏里的两个按钮分别用来“还原默认大小”和“全屏显示”。关闭设置再打开，上次调好的尺寸会被记住。

DSH 把设置弹窗固定成 800 × 800：在宽屏上两侧留白很大，在矮窗口里又可能超出屏幕，而设置项里没有调整尺寸的入口。这个插件让面板边缘可以拖动，在对话框自带的标题栏操作旁边增加“还原”和“全屏”两个按钮，并在尺寸变化时保持面板居中。

## 安装

1. 下载或克隆本仓库。
2. 在 DSH 中打开 **插件**，点 **添加插件**，选择这个文件夹（包含 `package.json` 的那一层）。
3. 刷新页面并打开设置。面板的四条边和四个角都可以拖动，鼠标移到边缘时指针会变化；标题栏里、关闭按钮左边、对话框自带操作按钮右边，会多出两个图标按钮。

插件以本地 bundle 的形式安装，读取的就是这个文件夹里的文件。移除 bundle 并刷新后，弹窗恢复 DSH 原版的 800 × 800，安装目录中的任何文件都没有被改写。

## 使用

| 操作 | 效果 |
| --- | --- |
| 拖动右侧或左侧边缘 | 在 560 px 到“视口宽度 − 48 px”之间调整宽度 |
| 拖动底部或顶部边缘 | 在 420 px 到窗口底部之间调整高度；顶边最高只到 DSH 标题栏下方 |
| 拖动任意一个角 | 同时调整宽和高 |
| 点击还原按钮 | 恢复默认的 800 × 800，并清除保存的尺寸 |
| 点击全屏按钮 | 铺满标题栏以下的窗口区域；再点一次恢复原来的尺寸 |
| 双击边缘，或聚焦后按 Home | 还原宽高并清除保存的尺寸 |
| 聚焦边缘后按方向键 | 左右键调宽度，上下键调高度，步长 16 px（按住 Shift 为 64 px） |

边缘和角落平时不画任何东西，只有鼠标指针变化和悬停提示告诉你它们在哪。拖动或用键盘调整时，面板右下角会浮出 `宽 × 高 px` 的尺寸徽标。边缘是可聚焦的分隔条，带无障碍名称和实时的 `aria-valuenow`；两个按钮都有 `aria-label` 和悬停提示，不用鼠标也能操作。

## 功能

- 左右两边调宽、上下两边调高、四角同时调，互不干扰。
- 标题栏里的还原按钮一键回到 800 × 800；全屏按钮铺满窗口，并且从标题栏下方开始，不会盖住窗口的最小化/最大化/关闭按钮。
- 两个按钮插在标题栏的正常排版流里，不会遮住对话框自带的“打开配置文件”等操作。
- 面板可以一直长到窗口底部，同时顶边停在标题栏下方；尺寸存进 `localStorage`，关闭设置、刷新页面后依然生效。
- 键盘可调：方向键微调、Shift 加速、Home 还原，每个控件都有悬停提示。
- 调整时显示尺寸徽标，界面文案提供中文和英文两套。
- 只在 768 px 及更宽的视口生效，即 DSH 渲染居中桌面弹窗的布局；更窄时 DSH 自带的满屏布局不做改动。
- 拖拽手柄是挂在 `<body>` 上的独立元素，位置取自面板的包围盒，面板的内边距、滚动条和圆角保持原样。
- 不改 DSH 的任何安装文件：禁用插件后，设置弹窗立即回到原样。

## 配置

插件没有设置页，只读写两项数据：

- 存储键：`dsh.settings-resize.width` 与 `dsh.settings-resize.height`
- 默认尺寸：800 × 800 px
- 最小尺寸：560 × 420 px
- 最大宽度：视口宽度减去 48 px
- 最大高度：从窗口底部到 DSH 标题栏下沿，面板变高时会向下移动，不会盖住窗口按钮

双击边缘、按 Home 或点击还原按钮都会删除存储值并回到 800 × 800。全屏状态不保存；关闭设置后，面板停在最后拖出的尺寸。

## 兼容性

基于 Windows 上的 DSH 0.2.2-rc.5 开发并测试。`package.json` 中的 `engines.dsh` 为 `>=0.1.0-rc.8 <0.3.0-0`，与其他已发布的客户端插件一致。

插件通过对话框的公开属性 `data-shortcut-modal="settings"` 找到面板。如果未来的 DSH 版本删除或改名这个属性，插件找不到面板，会保持静默，设置弹窗按原样显示。

## 实现说明

- `index.js` — bundle 的宿主端；运行时不注册任何东西。
- `client.js` — 全部功能：注入一个 `<style>`，在面板上设置两个 CSS 自定义属性；添加挂在 `<body>` 上的八个拖拽手柄；把两个按钮插进对话框标题栏；根据面板包围盒摆放手柄；处理指针和键盘输入。
- `cordis.patch.yml` — bundle 补丁，把插件挂进 DSH。
- `locale/en.json`、`locale/zh.json` — 插件名称、描述，以及手柄和按钮的文案。

尺寸通过 `<html>` 上的 `--dsh-settings-resize-width` 和 `--dsh-settings-resize-height` 生效，作用域为 768 px 及以上的视口；全屏是 `<html>` 上的另一个属性。`document.body` 上的 `MutationObserver` 负责在弹窗打开时挂载控件、关闭时移除。

## 开发

没有构建步骤，包内直接是 ES 模块。改完代码后运行 `node --check client.js`，再重装或刷新 bundle，打开设置即可看到效果。

仓库只有一层目录，`package.json` 的 `files` 字段列出了发布包需要的全部内容。
